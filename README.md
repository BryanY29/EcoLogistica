# EcoLogística

Proyecto Final - Sistema de Optimización de Rutas Sostenibles.

## Descripción del proyecto

EcoLogística es un sistema orientado a la optimización de rutas de distribución sostenibles, considerando la distancia recorrida y las emisiones de CO₂ generadas.

El proyecto se desarrolla bajo un **enfoque híbrido**, incorporando prácticas de Scrum para la gestión de los Sprints.

El ámbito de aplicación comprende los distritos de **El Tambo, Huancayo y Chilca**.

* **Backend:** FastAPI

* **Contenedores:** Docker Compose

* **Gestión ágil:** Scrum bajo enfoque híbrido
