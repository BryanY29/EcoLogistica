# 4. Control de supuestos

Los supuestos serán revisados periódicamente.

Cuando un supuesto deje de cumplirse se deberá analizar su impacto sobre:

- alcance;
- cronograma;
- costo;
- calidad;
- riesgos;
- arquitectura;
- desarrollo.

Si el impacto es significativo, se deberá registrar como riesgo o como solicitud de cambio según corresponda.

---

# 5. Control de restricciones

Las restricciones de severidad alta serán consideradas condiciones prioritarias del proyecto.

Cualquier modificación deberá ser evaluada por el Director del Proyecto.

Los cambios deberán analizar su impacto sobre:

- alcance;
- costo;
- tiempo;
- calidad;
- tecnología;
- riesgos.
