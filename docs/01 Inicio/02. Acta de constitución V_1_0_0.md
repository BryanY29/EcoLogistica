# 2. Propósito del proyecto

El proyecto EcoLogística tiene como propósito desarrollar un sistema de software orientado a la planificación y optimización de rutas de distribución dentro de El Tambo, Huancayo y Chilca.

El sistema permitirá gestionar información relacionada con pedidos, vehículos, conductores y puntos de entrega, y utilizar dicha información para generar rutas optimizadas.

La solución también incorporará indicadores relacionados con distancia, tiempo, consumo de combustible y emisiones de CO₂.

---

# 3. Justificación del proyecto

Las operaciones de distribución requieren una planificación adecuada para reducir recorridos innecesarios y aprovechar eficientemente los recursos disponibles.

Una planificación inadecuada puede generar:

- recorridos innecesarios;
- incremento del tiempo de entrega;
- mayor consumo de combustible;
- incremento de costos operativos;
- aumento de emisiones;
- dificultades para reaccionar ante cambios.

EcoLogística propone una herramienta tecnológica que permita apoyar la toma de decisiones mediante la generación y análisis de rutas.

La solución estará delimitada exclusivamente al ámbito de **El Tambo, Huancayo y Chilca**.

---

# 4. Objetivo general

Desarrollar un sistema web de gestión y optimización de rutas de distribución para El Tambo, Huancayo y Chilca, considerando criterios operativos y ambientales.

---

# 5. Objetivos SMART

## 5.1 Objetivo de alcance

Desarrollar un MVP funcional que implemente las funcionalidades prioritarias de gestión, optimización, visualización y evaluación de rutas dentro del ámbito geográfico definido.

## 5.2 Objetivo de cronograma

Completar las etapas de análisis, diseño, desarrollo, pruebas y documentación dentro del cronograma académico establecido para el proyecto.

## 5.3 Objetivo de costo

Mantener el desarrollo dentro del presupuesto aprobado por el equipo del proyecto y utilizar prioritariamente herramientas y tecnologías disponibles para el desarrollo académico.

## 5.4 Objetivo de calidad

Verificar mediante pruebas funcionales y técnicas que las funcionalidades prioritarias del MVP cumplan con los requisitos definidos.

## 5.5 Objetivo de sostenibilidad

Incorporar indicadores que permitan estimar el consumo de combustible y las emisiones de CO₂ asociadas a las rutas generadas.

5. Gestionar información de vehículos.

8. Generar rutas.

11. Considerar ventanas de tiempo.

13. Considerar tiempo estimado de recorrido.
14. Estimar consumo de combustible.
15. Estimar emisiones de CO₂.
