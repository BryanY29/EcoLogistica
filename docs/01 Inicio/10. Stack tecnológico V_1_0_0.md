# 7. Justificación técnica formal

La combinación **Python + FastAPI + React + PostgreSQL** es seleccionada para EcoLogística debido a su equilibrio entre capacidad técnica, mantenibilidad, gestión de información relacional y eficiencia de recursos.

PostgreSQL resulta apropiado debido a las relaciones existentes entre usuarios, vehículos, pedidos, rutas y entregas. El modelo relacional facilita la aplicación de restricciones de integridad y reglas de negocio.

FastAPI permite estructurar una API orientada a servicios y facilita la separación entre presentación, lógica de negocio y persistencia.

React permite construir una interfaz modular para las funciones de planificación, consulta de rutas e indicadores.

La selección también considera el objetivo de **Eco-Diseño**, buscando evitar consumo computacional innecesario mediante consultas optimizadas, procesamiento controlado y una arquitectura que pueda ajustarse al crecimiento real de la solución.

# 8. Relación con el enfoque híbrido

El stack tecnológico será establecido inicialmente mediante decisiones de arquitectura predictivas.

Durante las iteraciones se podrán realizar ajustes cuando exista evidencia técnica que justifique un cambio.

Los cambios deberán:

1. Registrar la decisión.
2. Identificar el impacto.
3. Evaluar riesgos.
4. Actualizar la documentación.
5. Mantener la trazabilidad mediante Git.

---

# 9. Decisión final

**Stack seleccionado:**

```text
Frontend: React
Backend: Python + FastAPI
Database: PostgreSQL
Control de versiones: Git + GitHub
Contenedores: Docker
Diagramación: Mermaid
```

La combinación se considera adecuada para el MVP de EcoLogística y para una futura evolución del sistema dentro del ámbito de El Tambo, Huancayo y Chilca.
