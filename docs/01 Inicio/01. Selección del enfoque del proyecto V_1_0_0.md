## 2. Descripción general del proyecto

EcoLogística es un proyecto orientado al desarrollo de un sistema de software para la gestión y optimización de rutas de distribución dentro del ámbito geográfico conformado exclusivamente por los distritos de **El Tambo, Huancayo y Chilca**, en la provincia de Huancayo.

El sistema busca apoyar la planificación logística mediante la generación de rutas eficientes, considerando variables como distancia recorrida, tiempo estimado de viaje, capacidad de los vehículos, ventanas de tiempo, consumo de combustible y estimación de emisiones de CO₂.

La solución contempla una plataforma digital que permita registrar información logística, generar rutas optimizadas, visualizar las rutas y consultar indicadores relacionados con el desempeño operativo y ambiental.

Asimismo, el sistema podrá realizar procesos de re-optimización cuando se produzcan cambios en las condiciones de operación, como modificaciones en los pedidos, disponibilidad de vehículos o restricciones de las rutas.

El proyecto será desarrollado bajo un **enfoque Híbrido**, combinando prácticas predictivas para los elementos que requieren planificación y definición previa, con prácticas iterativas para los componentes que requieren experimentación, evaluación y mejora continua.

Los objetivos generales del proyecto se encuentran definidos, principalmente en relación con la optimización de rutas dentro de El Tambo, Huancayo y Chilca.

Sin embargo, determinados aspectos deberán ser refinados durante el desarrollo, como:

- parámetros del algoritmo;
- criterios de optimización;
- restricciones específicas;
